Arduino Nano (atmega328, clone CH340) — DIY Arduboy clone
Display: 7-pin SPI OLED module, SSD1306, 128x64, 3.3V (NO onboard regulator)

================  PINOUT  ================

OLED (7-pin SPI module, R3 soldered = SPI mode):
  VCC  -> 3.3V (NOT 5V! module has no regulator)
  GND  -> GND
  D0 (SCL)  -> D13  (SCK)
  D1 (SDA)  -> D11  (MOSI)
  RES  -> D6
  DC   -> D4
  CS   -> D12

Buttons (Arduboy layout, active LOW — other end to GND):
  UP    -> A0
  DOWN  -> A3
  LEFT  -> A2
  RIGHT -> A1
  A     -> D7
  B     -> D8
  (INPUT_PULLUP: released = HIGH, pressed = LOW)

Buzzer (passive piezo, mono):
  Buzzer+ -> D5
  Buzzer- -> GND

Vibration motor (3-pin module, internal driver):
  SIG  -> D9
  VCC  -> 5V (or 3.3V)
  GND  -> GND

Onboard LED: D13 (also SCK — used for start indication before SPI init)

  OLED 7-pin SPI: VCC=3.3V, GND, D0=SCL->D13, D1=SDA->D11, RES->D6, DC->D4, CS->D12
  Buttons (active LOW): UP=A0 DOWN=A3 LEFT=A2 RIGHT=A1 A=7 B=8
  Buzzer: D5 (mono).  Vibro: D9 (3-pin module).

================  NOTES  ================
- CS must be a driven pin (D12), not GND.
- Module is write-only (no MISO) — cannot read chip ID over SPI.
- 3.3V display powers via SPI lines (parasite power) when VCC removed; to
  fully power off, also drive RES/D0/D1 low or cut all 7 wires.
- FQBN: arduino:avr:nano:cpu=atmega328old
- U8g2 constructor: U8G2_SSD1306_128X64_NONAME_1_4W_HW_SPI (HW_SPI, CS on D10)
  On ATmega328 D12=MISO is forced INPUT by HW-SPI, so CS on D12 can't go LOW →
  black screen. Use D10 (AVR SS pin) for CS with HW_SPI.
